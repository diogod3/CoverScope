# CoverScope v0.2.0-beta.2

This beta reduces the disk space left behind by reviews and makes it easier to find your way around the relationship graph.

## What's changed

- **Temporary-file cleanup:** completed and failed runs remove the baseline checkout and its restored packages, archive, and intermediate source indexes after saving evidence. Saved reviews, captured baseline source, and verification reports are kept.
- **Clean up earlier runs:** use **Runs → Clean temporary files** to reclaim temporary data from existing completed attempts. Cleanup failures stay visible and can be retried. Active collection is protected; unresolved attempts use the existing recovery flow after external processes have stopped.
- **Faster history discovery:** loading run history no longer scans restored package directories.
- **Show or hide tests:** the graph's **Show tests** filter is enabled by default. Turning it off hides types with recorded test definitions and their relationships. Helpers without test definitions remain visible.
- **Find a type:** search class/interface names or namespaces to highlight matching visible nodes. Next/previous navigation centers on a match; typing does not move the camera. Search respects the active type filters.
- **Cancellation test reliability:** the process fixture publishes its PID file after writing it completely, preventing the test from reading an empty file during startup.

## Update

```text
dotnet tool update --global DD3.CoverScope.Tool --version 0.2.0-beta.2 --source https://api.nuget.org/v3/index.json
coverscope
```

For a first installation, follow the [README](../../README.md#installation).

## Compatibility and validation

Saved reviews from `0.2.0-beta.1` remain readable. Reopen an existing run to use graph search and filtering; no new collection is required. Use the cleanup action to reclaim its temporary files. Saved-history retention is unchanged.

The release workflow checks build, tests, package contents, and installed-tool startup on Windows, Linux, and macOS before publication. Live graph interactions still require visual verification. See the [review guide](../review-guide.md) for controls and evidence limitations.
