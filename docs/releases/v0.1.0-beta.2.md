# CoverScope v0.1.0-beta.2

Beta 2 makes CoverScope faster to navigate and clearer to run as an installed .NET tool.

## Highlights

- **Responsive workspace switching** — parsed coverage reports now reuse cached Explorer and Metrics projections. The 45,000-line CI benchmark verifies cached switches without repeating expensive aggregation work.
- **Automatic explicit-target collection** — `coverscope MySolution.sln` opens the application and starts coverage collection once the interactive workspace is ready.
- **Branded collection progress** — manual and automatic runs show the real high-level collection phase and elapsed time with an accessible, reduced-motion-aware segmented-C animation.
- **Friendly local address** — CoverScope opens `http://coverscope.localhost:<port>` while Kestrel remains bound only to `127.0.0.1`. The numeric loopback URL is always printed as a fallback.
- **Preserved failure context** — failed tests continue to transition into structured results, and a previous successful report remains available when a rerun produces no replacement report.

## Install or update

CoverScope is distributed through the private GitHub Packages registry. Authentication instructions are in the repository README.

```bash
dotnet tool update --global DD3.CoverScope.Tool \
  --add-source https://nuget.pkg.github.com/diogod3/index.json
```

For a clean installation:

```bash
dotnet tool install --global DD3.CoverScope.Tool \
  --version 0.1.0-beta.2 \
  --add-source https://nuget.pkg.github.com/diogod3/index.json
```

## Known limitations

- The package remains private and requires GitHub Packages authentication.
- Coverage collection requires the .NET 10 SDK and `coverlet.collector` in the relevant test projects.
- On Windows, some non-browser HTTP clients do not resolve `coverscope.localhost`; use the printed `http://127.0.0.1:<port>` fallback. Chrome was verified with the friendly address in CI.
- Collection progress reports real coarse phases rather than an estimated percentage.
- Coverage output is written beside the selected solution or project under `coverage-output/`.
